# SCPSL-CustomRoles-O5

Серверный плагин на C# (.NET Framework 4.8) для *SCP: Secret Laboratory* на базе **LabAPI** и **UncomplicatedCustomRoles**, реализующий кастомные игровые роли и скриптовые сценарии раунда.

## Реализованные механики и роли
* **Совет O5 (O5 Council):** Спавн с отрядом МОГ на 20-й минуте раунда, управление освещением комплекса (`RoomLightController`), вызов подкрепления и запуск необратимой детонации боеголовки (`Warhead`).
* **Предатель МОГ / Шпион Хаоса:** Скрытая механика смены стороны и дружественного огня с временной защитой от урона на старте раунда.
* **Помощники SCP и Длань Змеи:** Кастомные классы с условным пацифизмом (щит до первого выстрела по цели) и интеграцией в систему фракций.

## Стек технологий
* C# / .NET Framework 4.8
* LabAPI (`PlayerEvents`, `ServerEvents`, `Warhead`, `RoomLightController`)
* UncomplicatedCustomRoles API
